# 🌌 3D 太阳系科普 —— 地球内部结构

一个互动式 3D 科普网页，使用 **Three.js** 构建。可以旋转、缩放太阳系，点击地球后会**剖切出 1/4 剖面**，展示地球内部的五个层次（内核、外核、下地幔、上地幔、地壳），并用科学数据讲解温度、深度、成分等知识。

> 🚀 **在线演示**：<https://sengc92.github.io/solar-system-3d/>

## ✨ 功能特色

- 🪐 **3D 太阳系**：八大行星 + 月球，基于 NASA 真实卫星纹理
- 🌍 **真实地球纹理**：8K 地球日景图、云层图、夜景图
- ☀️ **真实太阳**：太阳表面纹理 + Fresnel 日冕光晕 + 日冕粒子
- 🔪 **1/4 剖面视图**：点击地球，切掉 1/4 扇形露出真实同心圆实心剖面
- 📖 **严谨科普**：每层都有温度、深度、组成、状态、密度等科学数据
- 🔊 **语音朗读**：中文朗读每层的科普内容（Web Speech API）
- 🎮 **拼装小游戏**：按「内核→地壳」顺序点击各层
- ⏱️ **时间加速**：1/2×、1×、5×、20×、100× 公转速度调节
- 📏 **真实比例**：一键切换行星真实相对大小
- 🪐 **开普勒轨道**：真实轨道倾角 + 偏心率
- 🔴 **火星内部结构**：点击火星也能剖切看内部
- 🌕 **月球卫星**：绕地球公转的月球
- 💡 **随机小知识**：定时弹出地球趣味冷知识
- 🖱️ **点击其他行星**：弹出对应行星的趣味小知识 + 描边高亮

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
# 访问 http://localhost:5173

# 构建生产版本（输出到 dist/）
npm run build

# 预览生产版本
npm run preview
```

## 🎮 操作说明

| 操作 | 效果 |
|------|------|
| 鼠标拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 点击地球 / 火星 | 剖切查看内部结构 |
| 点击剖面各层 / 左侧按钮 | 查看该层详细信息 |
| 点击「🔊 朗读」按钮 | 语音朗读当前层讲解 |
| 点击「🧩 拼装游戏」按钮 | 按顺序点击各层 |
| 点击「📏 真实比例」按钮 | 切换行星真实相对大小 |
| 左下角时间面板 | 调节公转/自转速度 |
| 点击其他行星 | 弹出该行星小知识 |
| 点击太阳 / `ESC` / ✕ | 关闭剖面，回到太阳系 |

## 🧠 科普内容

包含地球内部五个层次（从内到外）：

| 层次 | 深度 | 温度 | 状态 |
|------|------|------|------|
| 🔥 内核 | 5150~6371 km | ~5400°C | 固态铁镍 |
| 🧲 外核 | 2900~5150 km | 4000~5000°C | 液态铁镍（产生磁场） |
| 🌋 下地幔 | 660~2900 km | 1900~3700°C | 固态（缓慢流动） |
| 🛤️ 上地幔 | 35~660 km | 500~1900°C | 部分熔融（软流层） |
| 🏔️ 地壳 | 0~35 km | ~15°C | 固态岩石 |

另包含**火星内部结构**（火星核、地幔、地壳）。

## 🛠️ 技术栈

- **Three.js**（3D 渲染，ACES 色调映射）
- **OrbitControls**（相机控制）
- **Raycaster**（点击拾取）
- **Web Speech API**（语音朗读）
- **真实天文纹理**（Solar System Scope 2K/8K 卫片纹理）
- **Vite**（构建工具）
- 纯原生 JS + CSS（无其他框架）

```
├── index.html          # 页面入口

```
